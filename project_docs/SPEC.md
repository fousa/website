# SPEC.md

## Problem Definition
The current personal website (fousa.be) no longer meets the standards the owner (a senior developer) wishes to project. It lacks a clear focus on professional history and freelance capabilities. There is a need for a digital business card that makes a technical impression and instantly convinces potential clients and recruiters.

## Target Audience
1.  **Potential Clients**: Looking for confirmation of expertise and previous successful freelance projects.
2.  **Recruiters/HR**: Want a quick overview of work experience (Timeline) and skills.
3.  **Peers/Developers**: Judging the technical quality and modernity of the site itself.

## Core Features (MVP)
*   **Parallax Timeline**: A visually attractive, scrollable display of the career path.
*   **Project Portfolio**: Filterable or clearly segmented overview of 'Client Work' and 'Personal Projects'.
*   **Downloadable CV**: Direct access to a PDF version of the resume.
*   **Unified Contact**: Prominent links to LinkedIn, Instagram, and Email.
*   **Mobile-First Design**: Graceful degradation of animations on mobile devices.
*   **Content as Code**: Management of projects and experiences via Markdown files in the repo.

## Out of Scope (for now)
*   Extensive blog functionality (can be added later).
*   Online CMS / Admin dashboard (we use Git + Markdown).
*   Multi-language support (start with English, TBD).
*   Dark/Light mode switch (opting for a single strong 'premium' aesthetic, likely dark mode).

## Success Criteria
1.  Successful deployment on Heroku via `git push`.
2.  Lighthouse score of 95+ on Performance and Accessibility.
3.  Framer Motion animations feel 'smooth' (60fps) on desktop.
